# IT Service Management — AI Prompt Library

A collection of tested prompts for IT service management, product ownership, 
and process documentation use cases.

Each prompt has been tested with Claude. The goal is to show how AI tools 
can assist IT professionals in daily work without replacing human judgment.

---

## 1. Incident ticket summary

**Use case:** Quickly understand and summarise an incoming IT support ticket

**Prompt:**^^
You are a technical business analyst assistant.
Translate the following German email into English and restructure it 
for a developer reading requirements for the first time.

Format the output as:
1. Summary — what needs to be done overall (2-3 sentences)
2. Tasks in sequence — numbered, with dependencies clearly noted
3. Pending clarifications — questions that need answers before work can start
